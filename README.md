# YP.ARC
건축 자료를 한 번에 만들어 주는 도구를 단계별로 만드는 프로젝트.

## v1 · 건폐율·용적률 검토기
대지면적과 용도지역을 넣으면 최대 건축면적·연면적을 계산하고, 계획안의 적합 여부를 판정해요.
`index.html`을 브라우저로 열면 바로 동작해요(설치 필요 없음).

| 파일 | 역할 (건물 비유) |
|---|---|
| `index.html` | 골조와 벽: 화면 구성 |
| `style.css` | 마감재: 색, 글꼴, 배치 |
| `app.js` | 설비: 버튼과 계산 연결 |
| `zoning.js` | 법규 데이터: 시행령 제84·85조 상한값 |

⚠️ 상한값은 국토계획법 시행령 기준이며, 실제 적용값은 지자체 도시계획조례로 확인해야 해요.

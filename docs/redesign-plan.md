## 1. 레퍼런스 정리

데스크톱 1440×900, 모바일 390×844에서 직접 열고 스크롤 위치마다 스크린샷을 찍어 확인했어요.
스크린샷은 스크래치패드 `ref/` 폴더에 있어요(`d-*` 데스크톱, `m-*` 모바일).

### 1-1. 사이트 구조

이 사이트는 한 페이지 앱이에요. 주소만 바뀌고, 페이지가 카드처럼 줄어들었다 커지며 넘어가요.

| 페이지 | 주소 | 하는 일 |
|---|---|---|
| 홈 (Cases) | `/` | 세로 스크롤이 없는 한 화면. 아래쪽에 작품 카드가 가로로 끝없이 돌아요 |
| Archive | `/archive` | 큰 제목 + 오른쪽 짧은 설명과 연도 범위(2016—2026) + 아래쪽 가로 이미지 띠 |
| About | `/about` | 세로 스크롤 페이지. 큰 문장 → About me → Philosophy → What I do → Global network → Core values → Process |
| 케이스 | `/cases/rains` | 세로 스크롤. 제목·정보·큰 이미지 → 큰 설명 → 번호 붙은 이미지 블록 01–06 → next case |
| Contact | (덮개) | 페이지 위에 큰 패널이 떠요. 탭 Client / Talent / Email + 예산·견적 폼 |

### 1-2. 그리드와 간격 (데스크톱 1440)

- 4칸 그리드예요. 가장자리 여백 16px, 칸 사이 8px로 한 칸이 약 397px이에요.
- 상단바도 같은 4칸에 맞춰요.
  - 1칸: 이름(두 줄)
  - 2칸: 로고
  - 3칸: Menu / Contact(두 줄)
  - 4칸: Local time + 둥근 다이얼
- 큰 제목과 문장은 1칸에서 시작해 2~3칸 폭을 차지해요.
- 설명 글은 3~4칸(화면 오른쪽 절반)에 놓여요.
- 홈 카드는 한 칸 폭(397×525, 세로형)이에요. 카드 위에 작품 이름(작은 대문자)이 있어요.
- 모바일:
  - 가장자리 8px, 카드 310×409이고 다음 카드가 옆으로 살짝 보여요.
  - About 글은 왼쪽 1/3을 비우고 오른쪽 2/3 칸에 놓여요.

### 1-3. 글자 크기 비율 (데스크톱 실측)

| 쓰임 | 크기 | 본문 12px 대비 |
|---|---|---|
| 상단바·라벨·캡션(대문자) | 12px | 1 |
| 본문·설명 | 18–20px | 약 1.6 |
| 큰 설명 문장(케이스 소개) | 40px | 약 3.3 |
| 페이지 제목·큰 문장(archive, about 첫 문장, next case) | 90px, 자간 -4% | 약 7.5 |

글자는 세 단계(작은 라벨 / 본문 / 아주 큰 문장)로 크게 벌어져 있어요. 중간 크기가 거의 없어요.

### 1-4. Menu 여는 방식

1. Menu를 누르면 지금 화면 전체가 카드 크기로 줄어들어요.
2. 화면에 페이지 카드 세 장(cases · archive · about)이 가로로 나란히 놓여요.
   - 카드마다 그 페이지의 실제 첫 화면이 축소되어 들어 있어요(제목 + 대표 이미지).
3. 카드 하나를 누르면 그 카드가 커지면서 해당 페이지가 돼요. 이게 페이지 전환이에요.

### 1-5. Contact 여는 방식

- 페이지는 어둡게 깔리고, 가운데에 큰 패널이 떠요(화면의 약 70% 폭).
- 패널 맨 위에 탭(Client / Talent / Email)과 CLOSE가 있어요.
- 큰 문장 아래에 번호 붙은 질문(01 Scope, 02 Format, 03 Budget…)과 체크박스가 있어요. 패널 안에서 스크롤돼요.
- 상단 오른쪽 다이얼에는 "Contact / Drag"라는 글이 있어요. 끌면 시계가 "Time Travel"로 바뀌는 장난감 같은 기능이에요.

### 1-6. 마우스를 올렸을 때

- **상단바 글자:** 글자가 두 벌 겹쳐 있어서, 올리면 위로 밀리며 같은 글자가 아래에서 올라와요(글자 굴리기). 글자 뒤에 작은 밝은 상자도 생겨요.
- **홈 카드:** 사진 안쪽이 살짝 확대된 상태(1.15배)에서 움직임에 따라 미세하게 따라와요(사진 속 시차).
- **Core values 카드 세 장:**
  - 하나에 올리면 그 카드의 사진이 화면 전체 배경으로 깔려요.
  - 세 카드는 얇은 테두리 상자가 돼요.
  - 올린 카드만 반투명하게 채워지며 설명 글이 나타나요.
- **Menu의 페이지 카드:** 올리면 살짝 커져요.

### 1-7. 스크롤 효과

- **홈과 Archive:**
  - 마우스 휠을 굴리면 카드 띠가 옆으로 흘러요(세로 스크롤 없음). 끝없이 반복돼요.
  - 움직이는 동안 카드가 0.9배로 살짝 작아지고, 카드 사이 간격이 벌어졌다가 멈추면 돌아와요.
- **About:**
  - 부드러운 스크롤(관성)이에요.
  - 큰 문장은 스크롤로 들어오며 한 줄씩 올라와요.
  - Process 구간은 화면에 고정돼요. 스크롤할 때마다 단계 이름(01 SEE … 06 EVOLVE)이 왼쪽으로 한 칸씩 밀려나요. 지금 단계만 진하고 나머지는 흐려져요.
  - 지금 단계 아래에 설명과 기울임 꼬리말이 바뀌어요. 스크롤이 단계마다 딱딱 멈춰요(약 540px 간격).
- **케이스:**
  - 첫 화면 오른쪽 큰 이미지는 위로 지나가요.
  - 제목과 정보 줄은 조금 늦게 따라 올라와요(시차).
  - 이미지 블록들은 폭과 시작 칸이 블록마다 달라요(4칸 전체 / 2–4칸 / 1.5–3.5칸 등). 아래에 "01.  CAMPAIGN DESIGN" 같은 번호 캡션이 붙어요.
- **상단바:** 내용 위에 겹쳐도 읽히도록 섞기 효과(difference)를 써서, 사진 위에서는 색이 뒤집혀요.

### 1-8. 페이지 전환

- Menu의 카드가 커지며 다음 페이지가 돼요(1-4).
- 케이스 맨 아래 "next case / 다음 작품 이름"(아주 큰 글자)과 오른쪽 아래 작은 썸네일을 누르면 다음 케이스로 가요.

### 1-9. 커서

- 따로 그린 커서는 없어요(기본 커서). 상단 오른쪽 다이얼이 커서 비슷한 둥근 요소로 보이는 정도예요.

### 1-10. 로딩 인트로

1. 어두운 화면 가운데에 작은 세로 사진 한 장이 나와요. 사진들이 빠르게 바뀌어요(플립북).
2. 동시에 상단의 손글씨 로고가 선으로 그려져요.
3. 약 3초 뒤 가운데 사진이 아래쪽 카드 띠의 한 칸으로 커지며 자리를 잡아요. 나머지 카드가 옆으로 펼쳐져요.

### 2-1. 초안으로 새로 써야 하는 글 (data.js에 "초안" 표시)

## 4. 먼저 정해야 할 것 (CLAUDE.md와 부딪치는 부분)

1. **글자 크기:**
   - CLAUDE.md는 "글자는 작게"이고, 지금 가장 큰 토큰 `--t-xxl`은 최대 64px이에요.
   - 레퍼런스는 큰 문장이 90px, 설명 문장이 40px이에요.
   - 따라 하려면 두 가지 중 하나를 골라야 해요.
     - ① `--t-xxl`을 키우고 40px짜리 토큰 하나를 추가하기
     - ② 지금 토큰으로 비율만 흉내 내기
